# CodeAI – Microsoft Reskill Internship

A collection of **Data Science, Machine Learning, Deep Learning, NLP, and Python projects** developed during the **Microsoft Reskill Internship**.

## 🎯 Problem

Learning AI and Machine Learning concepts requires more than theoretical understanding. Working with real datasets and implementing different algorithms helps bridge the gap between concepts and practical application.

This repository contains hands-on implementations covering:

* Data analysis and preprocessing
* Data visualization
* Statistical analysis
* Machine Learning
* Classification
* Deep Learning
* Natural Language Processing
* Sentiment Analysis
* Recommendation Systems

## 💡 Solution

The repository implements a series of practical notebooks and Python programs using real-world datasets.

Key implementations include:

* **Diabetes Analysis & Prediction** – data visualization, correlation analysis, ANOVA and Logistic Regression
* **Machine Learning Algorithms** – implementation and experimentation with different ML approaches
* **Classifier Evaluation** – analysis of model performance
* **CNN** – introductory deep learning implementation
* **Sentiment Analysis** – NLP-based analysis of review data
* **Book Recommendation System** – recommendation system using book datasets
* **Data Analysis with Pandas** – manipulation and exploration of datasets

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Simran250306/CodeAI-MicrosoftReskillInternship.git
```

### 2. Navigate to the project

```bash
cd CodeAI-MicrosoftReskillInternship
```

### 3. Install dependencies

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

Additional libraries may be required depending on the notebook being executed.

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```
(or use google colab)
Open any `.ipynb` file and run the cells sequentially.
